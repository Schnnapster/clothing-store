# ATELIER — інтернет-магазин одягу та аксесуарів

Сучасний односторінковий інтернет-магазин одягу та аксесуарів, реалізований на
чистих HTML, CSS та JavaScript — без фреймворків, збірників і зовнішніх залежностей.

Проєкт демонструє повний цикл покупки: каталог з фільтрами → кошик →
оформлення замовлення → підтвердження.

## Технології

- **HTML5** — семантична розмітка
- **CSS3** — CSS-змінні, Grid, Flexbox, `clamp()`, media-запити, анімації переходів
- **JavaScript (ES6+)** — модульний поділ логіки, делегування подій,
  `IntersectionObserver`, `localStorage`
- Без бібліотек, без білд-процесу — сайт відкривається як звичайні статичні файли

## Функціонал

### Каталог з фільтрами та сортуванням

- Фільтр за **категорією**: футболки, светри, штани, аксесуари
- Фільтр за **розміром**: S / M / L / XL
- Фільтр за **ціною**: поля «від / до» + повзунок верхньої межі
- Фільтр за **кольором**: кольорові кружечки (8 кольорів)
- **Сортування**: за популярністю, за новизною, ціна за зростанням / за спаданням
- **Пошук** по назві та опису товару в шапці сайту
- Чипи активних фільтрів — кожен можна прибрати окремо, або скинути все одразу
- Фільтрація та сортування відбуваються **без перезавантаження сторінки**:
  масив товарів фільтрується у JavaScript, сітка карток перемальовується динамічно

### Кошик покупок

- Бокова панель (drawer), що висувається справа
- Одна позиція кошика = товар + розмір + колір, тому одна модель у різних
  розмірах — це різні позиції, а повторне додавання того самого варіанта
  лише збільшує кількість
- Зміна кількості кнопками `+` / `−`, видалення позиції, очищення кошика
- Лічильник товарів у шапці з анімацією при додаванні
- Підрахунок суми товарів, доставки (безкоштовно від 1500 ₴) та суми до сплати
- Вміст кошика зберігається в `localStorage` — не губиться при перезавантаженні

### Оформлення замовлення

- Модальне вікно з формою: ім'я, телефон, спосіб отримання
  (доставка / самовивіз), адреса, спосіб оплати (при отриманні / карткою онлайн),
  коментар
- Валідація полів з підказками українською; при виборі самовивозу
  поле адреси приховується і не вимагається
- Підсумок замовлення з переліком товарів прямо у формі
- Після відправки — екран підтвердження з **номером замовлення**
  (формат `ATL-РРММДД-XXX`) та підсумковою сумою; кошик очищається

### Швидкий перегляд товару (quick view)

- Клік по фото товару відкриває модальне вікно з великим фото-заглушкою,
  повним описом, вибором розміру та кольору і кнопкою «Додати в кошик»

### Інше

- Легкий hover-ефект на картках: друга «заглушка» фото + плавне збільшення
- Тост-повідомлення про додавання та видалення товарів
- Закриття будь-якого вікна клавішею `Esc` або кліком по темному тлу
- Плавна поява блоків переваг та відгуків при скролі
- Повна адаптивність: 375px (фільтри згортаються в розкривну панель),
  768px, 1440px+

## Структура файлів

```
clothing-store/
├── index.html      # Розмітка всіх секцій, кошика та модальних вікон
├── style.css       # Усі стилі + адаптивність
├── products.js     # ДАНІ ТОВАРІВ: масив PRODUCTS, словники COLORS і CATEGORY_LABELS
├── catalog.js      # Фільтрація, сортування, рендер карток, quick view
├── cart.js         # Логіка кошика: додавання, кількість, підсумки, localStorage
├── checkout.js     # Оформлення замовлення: валідація, підтвердження
├── script.js       # Загальна ініціалізація, меню, Esc, анімації скролу
├── .gitignore
└── README.md
```

Порядок підключення скриптів важливий: `products.js` → `cart.js` →
`catalog.js` → `checkout.js` → `script.js`.

## Як запустити

### Найпростіший спосіб

Відкрийте `index.html` у браузері подвійним кліком.

### Через локальний сервер (рекомендовано)

```bash
python -m http.server 8125
```

Далі відкрийте http://localhost:8125 у браузері.

Або через Node.js:

```bash
npx serve
```

## Як додати або змінити товар

Усі дані про товари зберігаються на початку файлу `products.js` у масиві
`PRODUCTS`. Скопіюйте будь-який об'єкт і змініть поля:

```js
{
  id: 17,                          // унікальний числовий ідентифікатор
  name: 'Футболка «Нова»',         // назва
  price: 990,                      // ціна в гривнях
  oldPrice: null,                  // стара ціна або null, якщо знижки немає
  category: 'tshirts',             // tshirts | sweaters | pants | accessories
  sizes: ['S', 'M', 'L'],          // для аксесуарів — ['ONE']
  colors: ['black', 'white'],      // ключі з об'єкта COLORS
  popularity: 60,                  // 1..100 — для сортування за популярністю
  createdAt: '2026-08-01',         // дата появи — для сортування за новизною
  badge: 'Новинка',                // підпис на картці або null
  description: 'Повний опис для вікна швидкого перегляду.',
}
```

Нові кольори додаються в словник `COLORS` у тому ж файлі (ключ, назва
українською та HEX для кружечка) — вони автоматично з'являться у фільтрах.

## Обмеження демо

Це демонстраційний фронтенд-проєкт: бекенду немає, реальна оплата не
проводиться, замовлення не відправляється на сервер. Номер замовлення
генерується на клієнті.
